# MomentFlow v4 · 视觉故事与原声剪辑

日期：2026-10-24。扩展已有本地人脸识别链路，使用用户指定的 OpenRouter / OpenAI Luna。

## 处理流程

1. 本地人物识别与人工核对不变。每人出镜窗口依旧来自该人物实际关联的源媒体与时间点。
2. 按媒体来源和时间分散选取最多 36 个候选；照片取 1 帧，视频取首/中/末附近的 3 帧。检测到的非目标/不确定人脸先像素化，目标人脸标绿框。候选保留原媒体 ID、起止时间、目标可见性与输入画面哈希。
3. 经明确确认后，分批把画面与匿名候选 ID 发给 `openai/gpt-6-luna`。不发送姓名、人物特征、参考档案、原视频或原声。视觉提示明确不进行身份检索、能力/性格/发展评价或虚构声音/对白。
4. 第一次模型请求输出可见行为、活动类别、0–100 精彩评分、故事阶段、重复画面引用和支持描述的画面编号。后续批次附带最多 6 份已分析代表画面用于跨批次去重。服务端验证结构、候选集合、引用范围及目标可见性。
5. 结合模型明确的重复引用、评分、视觉近似度、活动重复、总时长和最多 8 段限制挑选，按开场/活动/收束整理。为有证据且尚未覆盖的故事阶段增加选择权重；固定机位中的不同活动不因全局画面相似就强制去重。不是以人脸大小排序，也不为了凑满时长重复画面。时间跨度只表示素材来源，不虚构同日进展或因果。
6. 第二次请求仅使用已选观察，生成标题、周记和逐段章节。章节必须与选段一一对应，不能生成未知片段。
7. 老师可修改故事标题、每段标题/字幕、周记，再采用草稿与推荐选段。采用之前不覆盖已有活动记录或影片。保留 `model_draft` 原始模型文字及观察记录，修改后的版本用于成片。
8. 成片写入标题和逐段字幕，并按所选顺序剪辑原画面/原声音轨。人工审核当前版本后才能交付。

## 配置与 API

- 固定 Base URL：`https://openrouter.ai/api/v1`。支持在设置页选择经当前公开模型目录核验的 GPT-6 Luna / Luna Pro 和 GPT-5.6 Luna / Luna Pro。
- `GET/PUT /api/model-config`：配置按签名本地会话隔离。API Key 原子写入数据目录，权限 0600，读取接口只返回是否已配置，不返回 Key。空缺参数保留现有 Key，显式空字符串移除。
- `POST /api/model-config/test`：不上传媒体，仅校验结构化请求连通性。
- `POST /api/projects/{id}/people/{person}/story`：需要人物确认、授权及独立的外部画面处理确认，返回后台任务。支持 5–60 秒目标预算，界面提供 15/30/60 秒。`locale` 为 `zh`（默认，兼容已有调用）或 `en`，决定新故事观察与草稿语言；界面切换不会改写已有用户内容。
- `POST .../story/apply`：校验当前来源签名、草稿 ID、标题、周记及逐段标题/字幕，更新人物记录和版本。
- `POST .../render`：增加 `preserve_audio`（默认 true）和可选 `story_id`。故事模式要求当前草稿已采用且选段集合一致，允许人工调整顺序；改选片段走手动生成，不套用不匹配的章节。
- OpenRouter 请求使用 JSON Schema、低推理开销、有限响应与 90 秒请求超时。无隐式模型切换、无失败自动重试，也没有预制文字兜底。网络、限额、无效 Key、截断/非法响应会明确失败，保留已有数据。
- 请求设置 `provider.require_parameters=true` 及 `data_collection=deny`。不将此参数等同于零保留承诺，服务条款以供应商为准。

## 版本与撤销

故事的来源签名覆盖分析版本、场景、人物 ID、姓名及全部脸观察 ID。新增媒体、重新分析、改名、分组纠错都会使历史草稿失效。编辑周记或重新渲染不使同一来源的故事观察失效，但会推进人物版本，使之前的影片审批和领取失效。

分析、请求、解析及选段全部成功后才原子写入新草稿。取消、无有效画面、模型返回错误引用等情况不替换旧草稿。采用草稿后刷新，推荐选段仍从已保存故事恢复，不回退为任意默认选段。

## 声音

视频帧仍由原视频按选段时间解码并逐帧遮盖人脸。对应原声用同一 `start` 截取，按输出帧数转为精确样本数的 48 kHz 双声道浮点 PCM：12 fps 下每帧 4,000 个样本，先重采样、补齐/裁齐，再拼接 PCM 并只编码一次 AAC，避免逐段 AAC 编码延迟累积。照片和无声视频补等长静音。视频各段独立编码为一致格式后拼接，不用循环原声或拼接无关音频填补空白。显式关闭原声则全部静音。

这是保留声音内容与时间关系的重新编码，不是位级无损复制。真实录音中的其他人声音、隐私对白和背景音乐不会自动移除，审核时需检查。

## 当前边界

- 模型分析的是采样视觉画面，不是全量时序视频，也不做语音转写或音频语义分析。短暂动作、遮挡及快速切镜可能漏掉。
- 模型观察和周记可能出错，来源引用只能检查其指向合法画面，不能自动证明每句文字真实；人工确认仍是交付环节。
- 像素化只覆盖检测到的人脸，不能保证匿名化。用户必须具备将候选画面交给外部模型处理的授权。
- 练习素材中的幼儿园人物为虚构儿童与照片合成视频；不能据此得出真实儿童的准确率。另提供真实托育课堂多人示例和成人烹饪课堂实测，保留来源录音；合成扫频音仅用于隔离的音频时序回归测试。
- API Key 必须由用户配置。契约测试使用隔离的测试传输替身，不属于应用逻辑，也不当作真实 Luna 调用证明。
