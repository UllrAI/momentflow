## 显示顺序 1

对应文件：[concept-01.png](concepts/concept-01.png)

Use case: ui-mockup. Create realistic, production-quality UI design for a Chinese kindergarten SaaS called 拾光成长. Concept name: 批次交付工作台. A focused primary teacher desktop screen at target 1440 x 1024, natural viewport ratio, flat screenshot filling canvas, no external frame. Current date anchor 2026-10-23 Friday, containing week 10月19日–10月23日. User outcome: teacher reviews each child's automatically assembled weekly memory video then delivers it to the authorized family. Design adult professional, calm warm off-white, dark forest green, a restrained amber accent, lovely real photographic thumbnails of fictional Asian kindergarten children doing crafts and outdoor play. Crisp Chinese typography 14–16px body, readable intentional spacing, narrow clean left nav, top breadcrumb 青禾幼儿园 / 向日葵班. Main heading 本周成长周记 with subtitle 先确认疑点，再把美好送到家长手中. One organized surface of child rows, not a grid of nested cards: child name, weekly film thumbnail and duration, 3 representative clip frames, status. Example rows 林小满 01:32 待审核; 周予安 01:18 待确认人物; 陈一诺 01:45 已审核. Selected child expands into a spacious preview and editable factual description in right pane. Header one main action 审核并交付, supporting action 导入素材. A small text summary 24位孩子 · 18份待审核 · 2项需确认. Highlight a precise identity question in context with small face crops and action 确认是林小满 / 移出周记. No emotion scores, growth scores, rankings or fake charts. No dense feature inventory, no gratuitous tabs, no decoration. Show realistic filmstrip and content, do not show bounding boxes on the family-facing preview. Clear hierarchy, typography, imagery, purposeful spacing. Prefer grouping and dividers over borders, no cards inside cards, shadows sparingly. No giant landing page hero, no marketing claims, no lorem ipsum. This is a conceptual mock with fictional data. Output exactly one independent screen, not a montage or multiple options.
