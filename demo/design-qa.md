## 主要交互与实际处理

- 中英文切换、页面标题/语言属性、刷新后偏好保留；设置、新建、导入、人物状态、片段、故事和领取页均检查。
- 从界面新建活动，自动打开导入引导，通过文件选择器上传完整课堂原片并启动识别，实际得到 15 个组。未使用预制分组填充工作空间。
- 真实课堂的照护者与孩子分别查看中英文影片；影片时长 7.5 秒、4 秒。原片完整播放 60.0266 秒；非静音且 `readyState=4`。
- 点击课堂章节，在成片约 4.5 秒、原片约 32.307 秒正确定位；烹饪第八章在成片约 24 秒、完整原片约 661.722 秒定位。两种模式都可播放，互不叠音。
- 通过浏览器下载 `child-a-en.mp4`；审核、交付、领取 API 下载内容与保存成品逐字节一致。
- 人物筛选联动、Story/Clips/People 标签、来源弹窗、章节展开、参考/合并/拆分入口与领取页可访问。空项目会引导导入；识别前后的加载、禁用状态真实反映后台任务。
- 窄屏选择人物后编辑器滚动到可见位置，返回列表有效。英文文件计数区分单复数，长人物 ID 不再作为预览按钮文案。
- 浏览器最终检查的 error / warn 日志为空。

## 自动检查与数据验证

- `npm test`：16 项后端与 5 项客户端测试通过，无跳过或新增警告。覆盖真实 OpenCV/FFmpeg、来源和审批边界、英文请求参数、虚构练习标签、双语文案、单复数及成品数据。
- Ruff、Prettier、生产构建、4 项既有 worker/打包测试通过。受保护的 hosting、worker、打包脚本和既有 worker 测试保持原样；没有新增 GitHub workflow。
- 六份展示影片完整解码无警告、H.264/AAC 与时长正确。课堂四份影片按章节与实际输入波形比对，相关系数 0.999330–0.999591、8kHz 精度下偏移 0ms。[可复跑检查与数值](qa/classroom/README.md)。烹饪观看副本的额外转码差异另行标注；实际导入源验证保留在[长视频记录](qa/real-activity/README.md)。

## 保留边界与后续

真实分组需要人工复核；长烹饪录像曾产生 287 个碎片组，不能宣称无人审核的识别准确率。采样分析可能漏掉动作，原声剪点可能截断对白，遮盖也可能漏检。课堂短片不代表完整一周。孩子 B 过短及英文分析未成功的情况已如实记录，未放入主示例。

账号、跨设备交付、实时流及支付仍未接入；生产可用性与识别准确率不在本次视觉验收结论中。代码开源许可证与素材人物权利检查列为后续公开前待办。没有剩余 P3 之外的视觉修复待办。

final result: passed
