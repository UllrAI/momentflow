# MomentFlow 应用指南

[简体中文](README.md) · [English](README.en.md) · [项目与效果展示](../README.md)

从照片、视频到每个人的原声影片。包含幼儿园与体验活动工作空间，以及可直接观看的真实课堂成品。

## 安装与启动

需要 Node.js 20.19+、Python 3.11–3.13、uv、FFmpeg/ffprobe。

```bash
cd demo
npm ci
npm run setup
npm run dev -- --port 4173
```

打开 http://localhost:4173 。界面右上角可切换简体中文和 English，刷新后保留。`setup` 安装后端并下载校验过的 OpenCV 模型；`dev` 同时启动前端与 127.0.0.1:8766 的 API，Ctrl+C 关闭二者。

`npm run build` 只构建前端与既有静态 worker，不包含 Python、FFmpeg 或账号服务。静态托管适合观看预先生成的示例，处理新素材仍需本地 API。

## 先看实际效果

进入“故事示例”：

- **托育课堂**：完整 60 秒多人原片，照护者与孩子各自的中英文影片、活动记录、章节跳转和下载。
- **手工意面课堂**：完整长视频的真实分析结果，八章、27 秒的原声影片；英文是对中文草稿的人工忠实翻译，选片一致。

查看示例不需要 Key、不重新推理、不产生模型费用。示例只是已保存的成品展示，不是新素材处理失败时的兜底结果。[素材与署名](public/examples/README.md)。

## 制作自己的故事

| 步骤 | 操作 |
| --- | --- |
| 导入素材 | 新建活动、确认权限，然后添加照片和视频 |
| 确认人物 | 开始识别，逐一核对分组；在“人物”中检查原始来源、合并或拆分 |
| 整理故事 | 在“故事”中请求 AI 推荐、修改标题、章节和记录，并点击“使用这份故事”；也可在“片段”中手动选片、排序、填写记录 |
| 审核交付 | 保留或关闭原声，生成影片；完整检查后审核，再交付至本机领取页并下载 |

可先登记单人清晰参考照片，再添加素材。姓名来自你的填写，不搜索外部身份库。低清、侧脸或遮挡可能漏检、拆成多个分组；不能把检测置信度视为身份正确概率。

JPG/JPEG、PNG、WebP、MP4、MOV、WebM、M4V、AVI 均可导入，但需本机解码器支持。单文件最多 100 MB，单视频最多 5 分钟、最高 4K；每活动最多 30 份、总计 500 MB。成片最多 12 段、60 秒，输出 1280×720、12 fps H.264/AAC MP4。

## 配置故事助手

1. 打开“设置”，选择 Luna 型号并填写 OpenRouter API Key，保存后可验证连接。
2. 确认人物和授权，在“故事”中同意将候选画面发送至 OpenRouter / OpenAI，再推荐故事。
3. 核对草稿并采用。修改来源或人物后需要重新分析；生成新影片后必须重新审核。

新故事跟随当前界面语言；切换界面不会翻译已保存的用户内容。没有 Key 时，仍可本地识别、手动选片、编写记录与生成影片。

分析最多使用 36 个按来源和时间分散的候选，视频每段最多 3 帧、照片 1 帧；模型不听取原声，不保证理解完整动作。目标框与检测到的其他人脸遮盖在本地完成，姓名、参考照片、特征和原声不会发送；漏检仍可能发生，需具备相应处理权限。接口可能计费，请按服务商约定使用。

## 数据管理与交付范围

- 数据保存在仓库根目录 `.momentflow-data/`，刷新或重启后继续使用，已加入 Git 忽略。模型权重保存在 `backend/models/`，安装器校验固定哈希，权重不提交。
- Key 按签名浏览器会话保存于本机、文件权限 0600；API 不回传密钥，不写入前端存储。删除活动不会删除 Key，可在设置中单独移除。
- 不同浏览器会话隔离项目。只有当前版本经审核并交付后才能从领取端下载；修改人物、记录、素材或影片会使相应旧版本失效。
- 领取页目前用于当前电脑与浏览器。尚未提供真实监护/游客账号、跨设备邀请、云存储或支付。
- 原声包含当时录入的全部声音，不能自动去除其他人说话；自动剪点可能截断对白。逐帧遮盖也只能处理检测到的人脸，必须完整人工复核。
- 设置中可确认删除当前活动的原片、特征、分组与影片。已下载到其他位置的文件需自行管理。

## 验证与排查

```bash
npm test
npm run check:backend
npm run check:format
npm run build
npm run test:sites
```

测试覆盖本地识别、视频动态、原声时序、故事来源、授权/版本边界、会话隔离、取消任务和双语文案。模型接口测试使用明确的测试替身；真实模型效果另有 [多人课堂记录](qa/classroom/README.md) 与 [长视频实测](qa/real-activity/README.md)。

无法连接工作空间时，确认通过 `npm run dev` 启动完整应用。模型未安装时重新运行 `npm run setup`。视频无法解码时，可先转为 H.264 MP4；上传失败时检查文件大小与时长。模型请求失败会保留已有结果，不自动替换成示例。
