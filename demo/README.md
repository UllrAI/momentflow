# MomentFlow Demo

面向体验运营商的照片纪念片交付演示。React 19 + Vite，纯前端、无账号、无真实支付。

## 运行

```bash
npm ci
npm run dev -- --port 4173
```

打开 http://localhost:4173 。推荐当前版本的 Chrome / Edge。`npm run build` 生成静态构建；不需要 API Key、后端或环境变量。

## 可以实际体验什么

1. 工作台选择林间滑索/山地卡丁车，查看场次、状态和素材。
2. 导入本地 JPG、PNG、WebP，最多 6 张、每张不超过 15 MB，或使用示例照片。文件不会上传。
3. 核对参与者及素材范围，确认使用与领取授权。这是人工核对演示，不是人脸识别或身份认证。
4. 打开成片工作室：选择片段、编辑字幕、前移片段、移除片段。
5. 点击生成预览：Canvas + MediaRecorder 将选定照片、轻微推镜及字幕实际编码为 1280×720 视频，每张 4 秒，无声。默认 WebM；支持的浏览器也可使用 MP4 编码。生成过程可取消，请保持页面可见。
6. 影片检查后确认成片，再单场或批量交付。修改内容会使旧渲染和审核失效；已交付版本锁定编辑。
7. 打开游客领取页，播放视频，模拟解锁 ¥49 套餐，下载真实生成的视频与当前场次照片，恢复本次会话中的购买权益。
8. 运营端订单页可见模拟记录；设置页可以重置。

最快路径：直接批量交付初始“可交付”场次 → 领取页 → 模拟解锁。初始示例视频是仓库内预先生成的 12 秒 MP4；编辑后的短片在浏览器内重新编码。

## 关键边界

- 素材归属、同行范围核对、成片版本确认、交付开放、付费权益分别保存状态。关联体验码不自动授予交付/下载权益。
- 无核对、未生成当前版本、未审核的内容不能交付；未交付的场次不能打开游客预览；未模拟购买不能使用下载按钮。
- 这些约束用于演示业务逻辑，**不是生产安全机制**。所有文件与状态都在客户端，没有后端鉴权、签名 URL、订单验签或媒体隔离。不能将此 Demo 用于真实私密影像交付。
- 仅保留当前页面会话。刷新、关闭页面或重置会丢失导入、编辑、视频 Blob 与模拟购买记录；游客链接不能跨设备独立领取。
- 场次、体验码关联及姓名来自演示记录；无自动人脸识别、视频输入/监控接入、AI 事件分析、云渲染或真实付款。
- 导入照片的主体范围需要人工判断。系统不会判断照片里是否出现陌生人。示例摄影由 AI 生成，多个示例场次复用素材。
- 输出为无声照片短片，不声称生成真实人物运动。视频导入、原片裁切、配乐和多模态选段是后续工作。

## 代码

- `src/model.js`：场次状态、审核版本、交付及购买规则。
- `src/render.js`：本地照片短片编码、进度、取消和资源释放。
- `src/App.jsx`：运营、工作室、游客及订单交互。
- `src/styles.css`：桌面与移动布局。
- `public/media/`：演示摄影、品牌裁片和预生成视频。
- `tests/model.test.mjs`：权限和版本边界测试。
- `qa/`、`design-qa.md`：浏览器截图和验收证据。
