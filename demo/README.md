# MomentFlow · 本地识别与个人集锦

这是带本地后端的可运行应用：真实照片/视频导入 → 检测与特征提取 → 人物聚类 → 人工核对 → 原片剪辑 → 审核 → 按人物领取。包含体验项目和幼儿园两种场景。

## 运行

前置：Node.js 20+、Python 3.11–3.13、uv、FFmpeg/ffprobe。无需 API Key 或云端识别账号。

```bash
cd demo
npm ci
npm run setup
npm run dev -- --port 4173
```

打开 http://localhost:4173 。`setup` 创建 Python 虚拟环境，下载并校验固定版本的 OpenCV 模型；之后处理可离线进行。`dev` 同时启动 127.0.0.1:8766 的本地 API 和前端，Ctrl+C 会关闭二者。

`npm run build` 构建前端静态资源，**不打包 Python/FFmpeg 服务**。原有 Sites worker 仅提供静态资源，不能单独部署完整识别功能。

## 幼儿园演示

1. 左侧选择幼儿园，点击“打开幼儿园示例”。
2. 服务登记三份虚构儿童参考档案，并分析两张照片和一段合成测试视频。模型实际检测到人物后才出现名单。
3. 选择人物，检查人脸切片与原始来源。点击“核对人物与授权”，检查姓名和全部切片。
4. 勾选所需片段，按需前移顺序，填写老师观察到的活动记录。
5. 生成真实 720p MP4，完整播放，检查其他人脸遮盖、画面和记录。
6. 审核当前成片 → 交付家长 → 家长领取页 → 下载。

示例儿童及姓名是虚构的；其中的视频由照片合成，不能用于证明真实儿童动态识别准确率。另有 OpenCV 授权真人动态视频，用于验证真实视频解码、匹配和动态片段输出。来源和提示词见 [samples/README.md](public/samples/README.md)。

## 导入自己的照片与视频

新建批次并确认处理授权，然后导入 JPG/JPEG、PNG、WebP、MP4、MOV、WebM、M4V 或 AVI。单文件 ≤100 MB、单视频 ≤5 分钟且最高 4K；每批最多 30 份、500 MB。文件需由当前机器的 FFmpeg/OpenCV 解码器支持。

可以先登记单人清晰参考照片，再导入活动媒体；也可先无监督聚类，再人工命名。姓名来自授权档案或人工填写，不从外部身份库检索。

- 抽帧间隔可选 0.5/1/2 秒。同一批次开始分析后保持统一间隔。
- 逐张/逐帧检测人脸，保留原媒体、时间点、框、检测质量和服务端特征。
- 完全链接相似度门槛与歧义间隔保守聚类，同帧不同人脸不会自动合并。转头或模糊可能拆成多个组，可人工合并；混人可选中切片拆分。
- 无人脸素材仍保留在素材库；过小或模糊人脸不强行匹配。人脸检测置信度不是身份正确概率。
- 出镜时间转换为源视频片段，不跨越未观察到的长时间段。视频片段保留源视频动态画面，照片展示 3 秒。最多选择 12 段、总长 60 秒。
- 输出为 1280×720、12 fps、无声 MP4。原声、配乐、实时摄像流、多模态精彩事件理解和自动成长评价尚未实现。
- 每个输出帧重新检测人脸，对不能可靠匹配目标人物的已检测人脸进行像素化。**漏检仍可能发生，不能把自动遮盖当成匿名化或零泄漏保证，交付前必须人工复核。**

## 状态、存储与访问

- 原文件、特征、分组、任务状态及影片保存于仓库根目录 `.momentflow-data/`，已加入 gitignore；刷新、重启后保留。处理失败/取消可重试，重启中断的任务会标为失败，不伪装完成。
- 识别模型保存在 `backend/models/`，ONNX 权重不入仓库；安装器验证固定 SHA-256。YuNet 为 MIT，SFace 为 Apache 2.0，许可证保留在该目录。
- 本地签名 HttpOnly/SameSite 会话隔离不同浏览器的项目；媒体没有公开静态目录，人物特征不会返回前端。变更操作检查本地来源与请求标记。
- 重新分析、修改人物/记录、纠错或重生成会使旧版本失效。未确认人物不能生成，未审核不能交付，失效/未交付文件不能从领取端下载。
- “家长/游客视角”是当前本地会话里的领取演示，**尚未提供真实教师/监护人账号、跨设备邀请、生产级组织权限或付费服务**。不要把本地演示页当作面向真实家长开放的系统。
- 设置页可明确确认删除当前批次及其中的原媒体、特征和影片。已下载到别处的文件需要自行管理。

## 验证

```bash
npm test
npm run check:backend
npm run check:format
npm run build
npm run test:sites
```

后端测试包含真实模型推理与 FFmpeg 输出，需要先运行 setup。覆盖图片和视频混合输入、参考档案、聚类与同帧约束、漏检素材、人工合并、目标/非目标遮盖、原文件不被缩略图覆盖、会话隔离、原视频动态输出、版本失效、审核交付和取消任务。测试失败不使用预制结果兜底。

详见 [当前验收记录](design-qa.md) 和 [实现说明](../docs/implementation-v3.md)。
